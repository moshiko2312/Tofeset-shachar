# משחק התופסת · שכב״ג שחר

אתר למשחק תופסת שרשרת של שכב״ג שחר (צופים).

- הרשימה של הילדים כבר נמצאת במערכת, והסדר שלה הוא הסדר של המשחק.
- בכניסה הראשונה כל ילד בוחר את השם שלו מהרשימה וקובע קוד אישי בן 4 ספרות. מאז הוא נכנס עם השם והקוד.
- כל אחד תופס את מי שבא אחריו ברשימה, והאחרון תופס את הראשון.
- תופסים? מצלמים את מי שנתפס דרך האתר. הנתפס מקבל הודעה ומאשר.
- 🧣 מי שחובש עניבת צופים אי אפשר לתפוס. הנתפס יכול לדחות תפיסה עם "הייתי עם עניבה".
- מי שתפס מקבל את המטרה של מי שנתפס. האחרון שנשאר מנצח.
- כל השרשרת גלויה לכולם. במחלוקת המדריך רואה את התמונה ומכריע.
- 📷 כל ילד יכול לערוך את הפרופיל שלו: להוסיף תמונה שמופיעה ליד השם בשרשרת ובכרטיס המטרה, ולהחליף את הקוד האישי.
- ⭐ המדריך מגדיר ילדים מהרשימה כמנהלים. מנהל יכול לחסום מי שעושה ספאם ולשחרר שם שמישהו אחר נכנס איתו.

## מבנה

| קובץ | מה יש בו |
|---|---|
| `index.html` | כל האתר: המשחק, השרשרת, החוקים, מסך מנהלים (`#mod`) ומסך מדריך (`#admin`) |
| `config.js` | הכתובת והמפתח של Supabase |
| `supabase/setup.sql` | הטבלאות וחוקי המשחק במסד הנתונים |
| `logo.svg`, `logo-full.svg` | הלוגו של שכב״ג שחר |

בלי `config.js` מלא, האתר עובד **במצב הדגמה**: הנתונים נשמרים רק בטלפון אחד. קוד מדריך בהדגמה: `1234`.

השמות של הילדים **לא** נמצאים ב-repo, כי הוא ציבורי. הם נשמרים רק במסד הנתונים.

## הקמה (פעם אחת, בערך 10 דקות)

### 1. Supabase (מסד הנתונים, חינם)
1. נכנסים ל-[supabase.com](https://supabase.com), יוצרים פרויקט חדש (אזור קרוב, למשל Frankfurt).
2. פותחים את `supabase/setup.sql`, ומחליפים את `shachar2026` בקוד המדריך שרוצים.
3. ב-Supabase: **SQL Editor → New query**, מדביקים את כל הקובץ ולוחצים **Run**.
4. טוענים את הרשימה: מריצים באותה דרך את קובץ הרשימה (`roster-shachar.sql`, נשלח בנפרד ולא נמצא ב-repo). אפשר גם להדביק את השמות במסך המדריך תחת **➕ הוספת ילדים**, שם בכל שורה.
5. ב-**Project Settings → API** מעתיקים את **Project URL** ואת המפתח **anon** (או **publishable**).
6. מדביקים את שניהם ב-`config.js`.

המפתח הזה מיועד להיות ציבורי. אי אפשר לקרוא או לשנות את הטבלאות ישירות, רק דרך פונקציות המשחק שבודקות קוד אישי, הרשאת מנהל או קוד מדריך.

### 2. GitHub Pages
1. ב-repo: **Settings → Pages → Build and deployment**.
2. Source: **Deploy from a branch**, Branch: `main`, תיקייה: `/ (root)`, **Save**.
3. אחרי דקה האתר עולה בכתובת `https://<user>.github.io/<repo>/`.

### 3. לפני המשחק
1. המדריך נכנס ל-`<כתובת האתר>#admin` עם קוד המדריך.
2. **⚙️ הגדרות → קוד גישה לאתר**: מומלץ מאוד. בלי הקוד אי אפשר לראות את השמות, והוא נכנס לבד מהקישור לילדים.
3. ליד כל שם יש **פעולות → ⭐ הפיכה למנהל**.
4. שולחים לילדים את הקישור מהמסך (יש כפתור וואטסאפ). כל אחד בוחר את השם שלו וקוד.
5. **▶ התחלת המשחק**. מי שעוד לא נכנס נשאר בשרשרת ויכול להיכנס גם אחרי ההתחלה.

## מנהלים (⭐)
ילד שהוא מנהל רואה לשונית **🛡️ ניהול**, ושם ליד כל שם:
- **🚫 חסימה**: הילד לא יכול לשלוח תפיסות או לאשר. תפיסה שהוא שלח ומחכה מתבטלת. הוא נשאר בשרשרת, ותפיסה שלו מאושרת על ידי המדריך.
- **🔓 שחרור שם**: מי שנכנס עם השם יוצא, והילד האמיתי נכנס שוב ובוחר קוד חדש. זה גם הפתרון לשכחת קוד.
- **🖼️ מחיקת תמונה**: מוחק תמונת פרופיל לא מתאימה.

מנהל לא יכול לחסום את עצמו או מנהל אחר. רק המדריך יכול.

## מסך המדריך
- אישור או דחייה של תפיסות, כולל צפייה בתמונה. אפשר לאשר גם בלי הנתפס.
- מחלוקות: תפיסות שהנתפס דחה (למשל בגלל עניבה). אפשר לאשר בכל זאת.
- מנהלים, חסימה, שחרור שם, מחיקת תמונה, שינוי שם, החזרה למשחק, מחיקה, הוספת ילדים (אחד או רשימה).
- סבב חדש עם אותה רשימה, או איפוס מלא.
- מחיקת כל התמונות בסוף המשחק.

## פרטיות
- תמונות התפיסה לא גלויות לכולם: רק הילד שצולם (כדי לאשר) והמדריך רואים אותן. מומלץ למחוק אותן בסוף המשחק.
- תמונות הפרופיל גלויות לכל מי שנכנס לאתר (עם קוד הגישה). הן קטנות, ונטענות מחדש רק כשמישהו מחליף תמונה.
- עם קוד גישה, מי שאין לו את הקישור לא רואה את השמות.
